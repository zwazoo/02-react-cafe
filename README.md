# Sip Happens Café

A simple feedback widget for a café. Users can rate their experience as Good, Neutral, or Bad and see live statistics.

## Stack

- React 19 + TypeScript
- Vite
- CSS Modules
- modern-normalize

## Getting started

```bash
npm install
npm run dev
```

## Scripts

| Command           | Description              |
| ----------------- | ------------------------ |
| `npm run dev`     | Start dev server         |
| `npm run build`   | Production build         |
| `npm run preview` | Preview production build |
| `npm run format`  | Format with Prettier     |
